# مركز غراس لتحفيظ القرآن الكريم — نظام الإدارة

نظام ويب عربي (RTL) متكامل لإدارة حلقات التحفيظ: الطلاب، المحفظون، أولياء الأمور، الحلقات، الحضور، الحفظ والمراجعة، التقييمات، التقارير، الإعلانات، الإشعارات والمراسلة.

- **الخادم:** PHP 8.3 · Laravel 12 · MySQL 8 (أو MariaDB 10.6+)
- **الواجهة:** Blade · Bootstrap 5.3 RTL · Bootstrap Icons · SweetAlert2 · Chart.js · خط Cairo
- جميع مكتبات الواجهة مضمّنة في `public/vendor` (لا حاجة لـ npm أو Vite، ويعمل بدون إنترنت عدا خط Cairo الذي يُستبدل تلقائياً بخط النظام).

---

## 1) التثبيت على Windows

### المتطلبات
1. **PHP 8.2 أو أحدث** (يفضل 8.3) — أسهل طريقة: [Laragon](https://laragon.org) أو [XAMPP](https://www.apachefriends.org) (يتضمنان PHP و MySQL).
   تأكد من تفعيل الإضافات في `php.ini`: `pdo_mysql`, `mbstring`, `openssl`, `fileinfo`, `intl`, `zip`, `gd` (مطلوبة لملفات PDF).
2. **Composer**: [getcomposer.org/download](https://getcomposer.org/download/)
3. **MySQL** (مع Laragon/XAMPP) أو MySQL Installer.

### الخطوات (من موجه الأوامر داخل مجلد المشروع)

```bat
:: 1. تثبيت حزم Laravel
composer install

:: 2. إنشاء ملف البيئة ومفتاح التطبيق
copy .env.example .env
php artisan key:generate
```

3. أنشئ قاعدة البيانات (من phpMyAdmin أو سطر أوامر MySQL):
```sql
CREATE DATABASE gharas CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

4. عدّل بيانات الاتصال في ملف `.env`:
```env
DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=gharas
DB_USERNAME=root
DB_PASSWORD=
```

```bat
:: 5. إنشاء الجداول + البيانات الأساسية (السور، الإعدادات، معايير التقييم) + بيانات تجريبية
php artisan migrate --seed

:: 6. ربط مجلد التخزين (مرة واحدة)
php artisan storage:link

:: 7. تشغيل الخادم
php artisan serve
```

افتح المتصفح على: **http://127.0.0.1:8000**

للعمل من **VS Code**: افتح المجلد من File ← Open Folder، وفيه مهام جاهزة (تشغيل الموقع بـ Ctrl+Shift+B، والتحديث، والاختبارات). التفاصيل في [`docs/VSCODE.md`](docs/VSCODE.md).

بيانات الدخول التجريبية موجودة في [`docs/DEMO_ACCOUNTS.md`](docs/DEMO_ACCOUNTS.md) (لبيئة التطوير فقط).

### إعادة بناء قاعدة البيانات من الصفر
```bat
php artisan migrate:fresh --seed
```

## 2) إنشاء حساب المدير الأول بطريقة آمنة (للإنتاج)

في بيئة الإنتاج (`APP_ENV=production`) لا تُنشأ أي حسابات تجريبية؛ يُضاف فقط جدول السور والإعدادات ومعايير التقييم:

```bat
php artisan migrate --seed --force
php artisan gharas:create-admin
```

الأمر يطلب الاسم والبريد وكلمة المرور (لا تظهر كلمة المرور أثناء الكتابة) ويتحقق من قوتها. بعد ذلك يُنشئ المدير بقية الحسابات من لوحة التحكم؛ **لا يوجد تسجيل عام**، ولا يمكن إنشاء حساب إداري إلا بواسطة مدير.

### قائمة تحقق الإنتاج
- `APP_ENV=production` و `APP_DEBUG=false` و `APP_URL=https://...` (استخدم HTTPS).
- `SESSION_SECURE_COOKIE=true` عند استخدام HTTPS.
- لا ترفع ملف `.env` إلى Git (مستثنى في `.gitignore`).
- `php artisan config:cache && php artisan route:cache && php artisan view:cache`
- اضبط البريد (`MAIL_*`) لتعمل استعادة كلمة المرور. في التطوير تُكتب رسائل البريد في `storage/logs/laravel.log`.

## 3) النسخ الاحتياطي

- من لوحة المدير: **الإعدادات ← تنزيل نسخة احتياطية الآن** (ملف SQL كامل، ولا يحتاج `mysqldump`).
- أو من سطر الأوامر: `php artisan gharas:backup` (تُحفظ في `storage/app/backups`).
- نسخة يومية تلقائية الساعة 2:00 إذا كان مُجدول Laravel يعمل (`php artisan schedule:work`، أو Task Scheduler في Windows يشغّل `php artisan schedule:run` كل دقيقة).
- الاستعادة: `mysql -u root gharas < storage/app/backups/gharas-....sql`

### أرشيف الأسابيع

- الأسبوع من الأحد إلى السبت. كل أسبوع منتهٍ يُحفظ ملفاً لكل حلقة (PDF بالعربية) في `storage/app/private/archives/{السنة}/{الشهر}/`.
- يُنشأ الأرشيف تلقائياً كلما فُتحت صفحة **السجل الأسبوعي والأرشيف**، فلا يحتاج Windows إلى مُجدول. ويمكن تشغيله يدوياً: `php artisan gharas:archive-weeks` (ويعمل أسبوعياً ليلة الأحد إذا كان المُجدول يعمل).
- انسخ مجلد `storage/app/private/archives` مع النسخة الاحتياطية للاحتفاظ بالملفات.

## 6) الوظائف المنفذة

**عام:** صفحة رئيسية (تعريف، رسالة وأهداف، الحلقات المتاحة، إحصائيات حية، إعلانات عامة، نموذج تواصل محمي من الإغراق)، دخول/خروج، استعادة كلمة المرور، صفحات أخطاء عربية، وتذكير بدعاء أو آية يظهر لكل مستخدم داخل النظام كل 3 دقائق (قابل للتعديل والإيقاف).

**المدير:** لوحة إحصائيات حية مع رسوم بيانية (الحضور، مستويات الطلاب، التقدم في الحفظ، سعة الحلقات، أحدث الأنشطة) · إدارة الطلاب (إضافة، تعديل، ملف تفصيلي، تفعيل/إيقاف/انسحاب، بحث بالاسم أو الرقم، تصفية بالحلقة والمحفظ والحالة، فرز، ربط ولي الأمر بكتابة جواله واسمه (يُربط بالحساب المسجل أو يُنشأ حسابه تلقائياً)، ربط بأكثر من ولي أمر، نقل بين الحلقات مع حفظ التاريخ) · إدارة المحفظين (الحساب، البيانات المهنية، الحلقات، عبء العمل، الحالة، نقل كل حلقاته إلى محفظ آخر دفعة واحدة مع خيار حذف حسابه، الإنذارات: تنبيه وإنذار أول وثانٍ ونهائي مع متابعة اطلاعه عليها) · إدارة أولياء الأمور (الحساب، التواصل، ربط الأبناء، حالة الارتباط) · إدارة الحلقات (الرمز، المحفظ، المستوى، الفئة العمرية، الأيام (من السبت إلى الخميس، والجمعة إجازة)، الموعد بساعة محددة أو بعد إحدى الصلوات أو بوصف حر مع السماح بتداخل مواعيد المحفظ، تغيير المحفظ أو إزالته بنقرة من صفحة الحلقة أو قائمة الحلقات، السعة، الحالة، منع تجاوز السعة إلا بصلاحية) · الحضور (يومي/أسبوعي/شهري مع النسب) · سجلات الحفظ (تصفية، تعديل، حذف موثق) · التقييمات ومعاييرها القابلة للتعديل · التقارير (المركز، الحلقة، المحفظ، الطالب) بفترة زمنية مع طباعة وتصدير CSV · الإعلانات بالفئة وتاريخ النشر والانتهاء مع إشعارات · الإعدادات (ومنها رسائل التذكير بالأدعية والآيات: تفعيلها ومدتها ونصوصها) · حسابات المديرين · سجل العمليات · رسائل التواصل · النسخ الاحتياطي · السجل الأسبوعي لكل حلقة وأرشيف كل الأسابيع والأشهر الماضية مع تنزيل ملفاتها.

**المحفظ:** لوحة بحلقات اليوم وحالة التحضير والرسوم البيانية · الجدول الأسبوعي · قائمة الطلاب · تسجيل الحضور (حاضر/متأخر/غائب/بعذر مع الملاحظات، وتحديد الكل) · تسجيل الحفظ الجديد والمراجعة والتثبيت (السورة، نطاق الآيات، الصفحات، الدرجة والتقدير، الأخطاء، الملاحظات، التوصيات، المشاركة مع ولي الأمر) · التقييمات · ملف الطالب والتقدم بالسور · تعديل بيانات طلابه وربط ولي الأمر بالجوال، وتعديل اسم ولي الأمر وجواله وتعيين كلمة سر جديدة له (لطلاب حلقاته فقط) · تغيير اسم حلقته وموعدها · تقارير حلقاته · الإعلانات · مراسلة أولياء الأمور · إنذارات الإدارة في لوحته مع زر «اطلعت» · سجلات هذا الأسبوع في اللوحة، وصفحة السجل الأسبوعي والأرشيف لكل الأشهر الماضية مع تنزيل ملف كل أسبوع.

**ولي الأمر:** بطاقات الأبناء (الحضور، الآيات المحفوظة، الغياب، آخر تسميع) · تفاصيل كل ابن (الحلقة والمحفظ والمواعيد، التقدم، الحفظ، الحضور، التقييمات، الملخص الشهري، السجلات الأسبوعية الحالية والسابقة مرتبة بالأشهر) · التنبيهات (الغياب، التسميع، التقييم، الإعلانات، الرسائل) · مراسلة المحفظ · الملف الشخصي.

**الزائر / الداعم:** سير الحلقات والتقارير الشاملة، والسجل الأسبوعي وأرشيف كل الأسابيع السابقة لكل الحلقات مع تنزيل ملفاتها، بأسماء مختصرة ودون ملاحظات المحفظ، اطلاعاً فقط.

**الأمان:** حماية CSRF، تشفير كلمات المرور، تحديد معدل محاولات الدخول، الحماية من الإسناد الجماعي للدور والحالة، Policies لكل سجل، إخراج الحسابات الموقوفة فوراً، تسجيل العمليات الحساسة بدون كلمات المرور، حماية تصدير CSV من حقن الصيغ.

## 7) ما يحتاج إلى إعداد خارجي
| الميزة | المطلوب |
|---|---|
| إرسال رابط استعادة كلمة المرور بالبريد فعلياً | ضبط `MAIL_MAILER` و `MAIL_HOST`... في `.env` (حالياً `log`) |
| إشعارات البريد / SMS | النظام جاهز: أضف قناة `mail` أو قناة SMS في `SystemNotification::via()` مع إعداد المزود |
| النسخ الاحتياطي اليومي التلقائي | تشغيل مجدول Laravel (`schedule:run` كل دقيقة) |
| الشعار الرسمي | استبدال الأيقونة في `resources/views/partials/brand.blade.php` بصورة الشعار |
| تصدير PDF | غير منفذ؛ استخدم زر «طباعة» ثم «حفظ كـ PDF» من المتصفح (صفحات الطباعة منسقة) |

## 8) افتراضات موثقة
- الطلاب لا يملكون حسابات دخول؛ يتابعهم أولياء الأمور.
- الطالب ينتمي إلى حلقة واحدة حالية، ويُحفظ تاريخ انتقالاته.
- يوجد سجل حضور واحد لكل حلقة في اليوم.
- الدرجة من 100 وتُشتق منها التقديرات: ممتاز ≥90، جيد جداً ≥80، جيد ≥70، مقبول ≥60، ضعيف أقل من ذلك.
- أيام الأسبوع تبدأ من الأحد، والمنطقة الزمنية الافتراضية `Asia/Riyadh` (قابلة للتغيير عبر `APP_TIMEZONE`).
