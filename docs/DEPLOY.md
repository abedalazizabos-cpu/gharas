# رفع الموقع على الاستضافة

دليل مختصر لرفع نظام غراس على استضافة تدعم PHP 8.3 وMySQL (مثل cPanel أو Plesk أو خادم VPS).

## قبل الرفع

- PHP 8.3 أو أحدث، مع الإضافات: `pdo_mysql`، `mbstring`، `gd`، `zip`، `intl`، `fileinfo`، `openssl`.
- قاعدة بيانات MySQL أو MariaDB فارغة، مع اسمها واسم المستخدم وكلمة المرور.
- شهادة SSL مفعّلة للنطاق، فالموقع يعمل على https.

## الخطوات

1. **ارفع ملفات المشروع** من GitHub، دون مجلدَي `vendor` و`node_modules`. يمكنك رفعها بـ `git clone` أو بملف مضغوط.
2. **اجعل مجلد الموقع يشير إلى `public`.** في لوحة الاستضافة اجعل جذر النطاق (Document Root) هو مجلد `public` داخل المشروع، فهذا الأكثر أماناً. إن لم تسمح الاستضافة بذلك وكان المشروع كاملاً داخل `public_html`، فملف `.htaccess` الموجود في جذر المشروع يحوّل الزيارات إلى `public` ويمنع الوصول إلى بقية الملفات.
3. **ثبّت المكتبات بدون أدوات التطوير.** هذا يقلل الحجم ويسرّع التحميل:
   ```
   composer install --no-dev --optimize-autoloader
   ```
4. **أنشئ ملف الإعدادات:** انسخ `.env.production.example` باسم `.env`، وعدّل القيم المعلّمة بـ «غيّر» (الرابط وقاعدة البيانات والبريد). ثم نفّذ:
   ```
   php artisan key:generate
   ```
5. **جهّز قاعدة البيانات والكاش:**
   ```
   composer deploy
   ```
   ينفّذ هذا الأمر `migrate` ثم `optimize`. لا تُنشأ البيانات التجريبية على الاستضافة.
6. **أنشئ حساب المدير الأعلى الأول:**
   ```
   php artisan db:seed --force
   php artisan gharas:create-admin
   ```
   الأمر الأول يضيف السور والإعدادات الأساسية فقط.
7. **اضبط صلاحيات المجلدات:** يجب أن يكون `storage` و`bootstrap/cache` و`public/uploads` قابلة للكتابة من الخادم.
8. **فعّل المهام الدورية (Cron)** من لوحة الاستضافة، بأمر يعمل كل دقيقة:
   ```
   * * * * * cd /path/to/gharas && php artisan schedule:run >> /dev/null 2>&1
   ```
   هذا يحفظ أرشيف الأسابيع كل أحد، وينشئ نسخة احتياطية يومية في `storage/app/backups`.

## عند كل تحديث لاحق

```
git pull
composer install --no-dev --optimize-autoloader
composer deploy
```

## ما يحمي الموقع تلقائياً

- لا تظهر تفاصيل الأخطاء للزوار عندما تكون `APP_DEBUG=false`.
- تُرسل جلسة الدخول مشفّرة وعبر https فقط، وتُحوَّل كل الروابط إلى https.
- محاولات الدخول محدودة بـ 10 في الدقيقة، ونموذج التواصل بـ 5 في الدقيقة.
- ترويسات حماية تمنع تضمين الموقع في مواقع أخرى وتخمين نوع الملفات.
- لا يمكن تنفيذ أي سكربت داخل مجلد الملفات المرفوعة.
- على الخادم تُمنع الأوامر التي تمسح قاعدة البيانات كاملة، مثل `migrate:fresh`.
- الملفات المخفية مثل `.env` لا تُعرض أبداً.

## تنبيهات

- لا ترفع ملف `.env` إلى GitHub أبداً، واجعل المستودع خاصاً (Private).
- لا تستخدم حسابات البيانات التجريبية (كلمة المرور `password123`) على الاستضافة.
- احتفظ بنسخة من النسخ الاحتياطية خارج الخادم من حين لآخر.
